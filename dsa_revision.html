🪟 Sliding Window

Continuously expand right boundary to satisfy or break a constraint, then contract left boundary to restore validity or minimize window. Converts O(N^2) subarray problems to O(N).

1def dynamic_window(s: str) -> int:
2 seen = set()
3 l = max_len = 0
4 for r in range(len(s)):
5 while s[r] in seen: # Short-circuit contract
6 seen.remove(s[l])
7 l += 1
8 seen.add(s[r])
9 max_len = max(max_len, r - l + 1)
10 return max_len

4 mid = (l + r) // 2

🌲🔙 Backtracking

Systematically explore a state tree by making a choice, recursing into sub-choices, and undoing the choice to restore previous state.

Python3 ▾
1def backtrack(nums: list[int], target: int) -> list[list[int]]:
2 res, path = [], []
3 def dfs(idx: int, remaining: int):
4 if remaining == 0: return res.append(path[:]) # Goal hit
5 if remaining < 0: return # Short-circuit prune
6 for i in range(idx, len(nums)):
7 path.append(nums[i])
8 dfs(i + 1, remaining - nums[i])
9 path.pop()
10 dfs(0, target)
11 return res
