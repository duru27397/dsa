Turn repeated lookups into constant-time memory checks, then use ordering and moving boundaries to shrink the search space.

def findMatch(items: List[int], target: int) -> bool:    """    Target = 9    Items:  [2,  7, 11, 15]                 ▲   ▲                 2 + 7 = 9 (Match found!)    """    seen = set()    for item in items:        complement = target - item        if complement in seen:            return True  # O(1) memory lookup for past items        seen.add(item)    return False

⚡ Hash Maps & Sets

Trade space for time: turn linear searches into constant-time lookups using sets or frequency maps.

Remember what you have seen

Use when: the question asks whether a value, complement, or frequency has appeared before.

Why it works

A set or dictionary turns a full scan for the previous value into an average O(1) lookup. The loop only moves forward once.

seen = set()for x in nums:    if x in seen: return True    seen.add(x)
Core Techniques

Sub-Techniques to Recognize

Hash Set Lookups

Record each visited number in a set. If the current number already exists in the set, a duplicate is immediately identified in O(1) average time.

Complement Map

Store target - current in a dictionary with indices. Check for complement matches in O(1) time without nested iterations.

⚡ Prefix & Suffix Accumulation

Avoid repeated passes and nested loops by pre-aggregating cumulative prefix/suffix values or identifying streak roots.

Build information once

Use when: each answer depends on everything to the left or right, or repeated work is hiding inside a nested loop.

Why it works

A prefix or suffix stores the accumulated result before the current index. Each position then combines two ready-made answers in O(1).

prefix = 1for i in range(n):    answer[i] = prefix    prefix *= nums[i]
Core Techniques

Sub-Techniques to Recognize

Product Except Self

Accumulate prefix products in a forward pass, then multiply by suffix products in a backward pass to solve without division in O(n).

Sequence Start Streaks

Convert numbers to a set. Only begin counting sequences when num - 1 is absent, ensuring linear O(n) total amortized work.

Use ordering and monotonic invariants to rule out suboptimal candidate ranges in constant time per step.

Move a boundary with proof

Use when: the input is sorted, or the answer lives inside a contiguous window or between two pointers.

Why it works

Each move discards a region that cannot improve the answer. A monotonic invariant makes the linear scan safe instead of speculative.

left = 0for right, x in enumerate(nums):    while window_is_invalid():        left += 1

📈 Dynamic Programming: Overview & Blueprint

Name the state, write the transition, and keep only the history the next decision actually needs.

Python 3 ▾ 
def solve(states: List[int]) -> int:    """    states: [s0, s1, s2, s3, ...]    Only store minimal history (prev2, prev1) to reach next state    """    prev2, prev1 = 0, 0    for state in states:        current = transition(prev2, prev1, state)        prev2, prev1 = prev1, current    return prev1  # keep only useful history
Topic 02 · Subcategory 01

📈 1D State Transitions

Summarize the subproblem into minimal state variables and advance through transitions without recomputing overlapping branches.

State + transition

Use when: the answer at position i depends on a small, fixed amount of earlier work.

Why it works

The state summarizes every relevant way to reach the current position. The transition considers the allowed previous moves exactly once.

prev2, prev1 = 0, 0for value in nums:    prev2, prev1 = prev1, max(prev1, prev2 + value)
Core Techniques

Sub-Techniques to Recognize

Climbing Stairs (Linear)

Each step is reached from i-1 or i-2. Add combinations iteratively to calculate distinct ways in linear time.

When computing dp[i] = max(dp[i-1], dp[i-2] + val), retain only two scalar variables rather than an entire array.

📈 Knapsack & Decisions

Decide whether to include or exclude an item, updating optimal capacity states or reachability masks.

Choose, skip, or carry

Use when: each item offers a choice and the answer tracks a capacity, budget, or reachable prefix.

Why it works

Every valid solution either takes the current choice or does not. The recurrence keeps the better or reachable result for each smaller state.

for capacity in capacities:    skip = dp[capacity]    take = dp[capacity - cost] + value    dp[capacity] = max(skip, take)
Core Techniques

Sub-Techniques to Recognize

Coin Change (Unbounded)

For each coin/item, update each achievable amount by choosing the minimum between skipping the coin or taking one more.

Practice: Coin Change ↗

Word Break (Reachability)

Maintain a boolean array where dp[i] indicates whether substring s[:i] can be segmented using valid dictionary words.

📈 Sequence & String DP

Structure recurrences along sequence or string dimensions, converting exponential branching into polynomial time.

Grow a sequence carefully

Use when: a string or sequence has overlapping prefixes, suffixes, or choices between neighboring positions.

Why it works

Overlapping subproblems are cached once. The recurrence follows the structure of the sequence, so exponential branching becomes polynomial work.

dp = [1] * nfor right in range(n):    for left in range(right):        if can_extend(left, right): dp[right] = max(dp[right], dp[left] + 1)
Core Techniques

Sub-Techniques to Recognize

Longest Increasing Subseq

Let dp[i] be the length of the longest increasing subsequence ending at index i. Query prior valid indices to extend in O(n²).

Practice: Longest Increasing Subsequence ↗

Decode Ways (Strings)

Count valid ways to decode by evaluating single-digit (1-9) and two-digit (10-26) valid transitions simultaneously.
