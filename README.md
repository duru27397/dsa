# DSA Revision & Interactive Roadmap

Comprehensive Data Structures & Algorithms revision repository containing 150 essential LeetCode problems across 18 core topics.

## 🚀 Features

- **Interactive Visual Roadmap DAG**: Dependency graph illustrating prerequisite relationships across all 18 topics from Level 0 to Level 7.
- **1 to 5 Star Difficulty Tiers**: Clear difficulty ratings (`★☆☆☆☆` to `★★★★★`) categorizing problems from fundamental warmups to ultra-hard challenges.
- **Python 3 Short-Circuit Blueprints**: Concise, high-yield algorithmic templates highlighting core loops, data structures, and early returns.
- **100% LeetCode Official Links**: Direct links to all 150 problems on LeetCode.
- **W3Schools & LeetCode UI Style**: Responsive side panel with 3-level tree navigation, Monaco/VSCode dark syntax highlighting with line numbers.
- **Progress Tracking**: Persistent checkbox tracking via browser `localStorage`.
